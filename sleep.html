One-time iPhone setup (2 minutes)
  1. Open the Shortcuts app → + to make a new shortcut. Name it Hish Alarm.
  2. Add the action Get Dates from Input (input: Shortcut Input).
  3. Add the action Create Alarm (Clock). Set Time to Dates and label it Hish sleep. Open its options and turn off Show When Run.
  4. Tap the (i) at the bottom and make sure Receive includes Text.
  5. Back here, tap Going to bed. The first time, iOS asks to allow Hish to open Shortcuts — tap Allow.
Fully automatic option: in Shortcuts → Automation → + → Sleep (or Focus → Sleep) → When Sleep Focus turns on → action Open URLs with https://hish-six.vercel.app/sleep.html?auto=1 → set it to Run Immediately. Then just switching on Sleep Focus sets the alarm.
Each night creates a new "Hish sleep" alarm in the Clock app. Old ones stay but are one-off, so they won't ring again — swipe to delete them now and then.
Android notes
Tapping Going to bed asks your Clock app to create the alarm directly. Some phones block this from the browser — if nothing opens, the wake time stays on screen so you can set it by hand, or add Hish to your home screen and try from there.
